## Featured projects

### Shiraz Beauty (`shirazbeauty`) — private, coming soon

A city-scoped directory and booking platform for beauty, dermatology, laser, and hair-transplant clinics in Shiraz ([shirazbeauty.ir](https://shirazbeauty.ir)).

It is designed for three audiences:

- Clients, who can search for a specialist and book in Jalali dates
- Clinics, who manage a profile, service catalogue, and appointment slots
- Platform admins, who handle clinic verification and moderation

The stack is Next.js 16 (App Router, TypeScript, React 19) and Tailwind CSS on the frontend, FastAPI with SQLAlchemy and Alembic on the backend, PostgreSQL 16 for data, and Docker Compose with an nginx reverse proxy for deployment. Authentication uses mobile OTP and JWT.

The GitHub repository is currently private and will be linked here if it is published.
